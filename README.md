# Lab_12
Варіант 17:Написати програму для порівняння двох дат, задані у форматі ДД:ММ:РР. Вивести введені дати у хронологічному порядку.
Програма призначена для порівняння двох дат у форматі ДД:ММ:РР.
Користувач вводить дві дати, програма перевіряє їх коректність — враховуючи кількість днів у місяці та високосні роки — після чого виводить їх у хронологічному порядку та повідомляє результат порівняння.
Після кожного порівняння програма питає чи продовжити роботу. Всі виконані порівняння зберігаються в історії, яка виводиться у вигляді таблиці після завершення роботи.
Програма реалізована як багатофайловий проєкт з 5 файлів: структури і глобальні змінні описані у date.h, логіка роботи з датами — у date.cpp, функції виведення — у display.h та display.cpp, головна функція main — у prog.cpp.
